# 场景 Studio · 第三版设计方案

本版按用户确认方向重做，独立单文件 HTML，打开直达产品首页。仅模拟交互，不修改正式官网、不调用生成 API。

## 页面布局

- 桌面左侧 200px 轻导航：新建创作、当前对话；底部独立设计评审入口。
- 主区最大 1100px，宽输入框是首个视觉重心。Slogan 与可点击 IP 紧贴输入区。
- 输入框只保留文本、素材缩略图和上传、比例、场景、数量、生成操作。默认 3:4 / 两种都要 / 2 张。
- 下方三列 3:4 场景卡片；手机端两列。卡片是自制 SVG 构图示意，不是假称真实生成作品。

## Chat 与预览

生成后进入二级 Chat 页，保留页面外框。需求快照紧凑呈现，过程模块可展开，图片墙占主体。底部固定继续输入区，每轮追加新结果，旧结果不覆盖。

生成完成出现 3 秒 Toast。点击图片进入居中大图预览，支持前后切换、下载、关闭及键盘操作。不添加未支持的右侧工具栏。

## 视觉

背景 #111112，侧栏 #171718，输入框 #202022，以明度建立层次。白灰按钮、低对比边界、较大留白。IP 使用 CSS 体积光影与轻量点击反馈，不需要视频资源。

## 评审与状态

产品 UI 外的“页面与设计说明”入口承载全页面结构稿和详细说明；右下“演示状态”可注入首页、就绪、生成中、完成、预览、多轮、上传失败和生成失败。

自然语言、多轮上下文仍为拟议交互，正式接入前需核验 Dify 工作流。示意生成约 4 秒，上传仅本地读取，下载为 SVG；不承诺正式生成耗时。


## 素材更新

首页 IP 已替换为用户提供的抱鱼小猫，Logo 为墨镜猫；示例区改为用户文件夹中的 6 张原始图片。所有素材内嵌到 HTML，卡片保持 3:4，放大查看和下载使用原始图片。
