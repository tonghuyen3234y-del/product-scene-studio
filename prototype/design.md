# 形意 Logo · 灰阶交互原型

## 页面架构
- 首页：左侧「开始创作 / 历史记录」，中央品牌需求输入框，下沿集中配置风格、比例、数量；下面 6 种 Logo 灵感案例。
- Chatflow：按轮展示需求、参数、实际模拟阶段和结果图片墙，底部固定修改输入框。
- 历史记录：本浏览器保存的模拟创作列表，点击恢复完整对话。
- 图片预览：模态层放大、上一张/下一张、单张下载、关闭。

## 核心交互
1. 输入品牌名称、行业或需求；也可点击灵感案例填入需求和风格。
2. 选择 6 种风格之一、图片比例和 1–4 张数量，默认比例 3:4、数量 2。
3. 点击生成进入 Chatflow，约 4 秒模拟「理解需求 → 探索方向 → 构建方案 → 整理结果」。
4. 生成成功展示图片墙，Toast 3 秒消失。点击图片进入预览，左右键和按钮切图，Esc 关闭。
5. 底部提交修改需求，追加新一轮结果，保留上一轮。模拟数据只展示方案变化，不执行真实语义设计。
6. 首页底部「演示生成失败」进入失败流程，保留需求，点击「重新生成」恢复成功路径。
7. 空输入会就地提示；任务进行中禁止重复生成；历史为空时提供开始入口。

## 与参考布局的差异
保留「左导航 + 中央创作输入 + 下方灵感」的阅读顺序，但使用浅灰线框与单一 Logo 工作流。没有 Agent 类型、模式切换、积分、活动、复杂编辑工具或内容流。灵感案例直接带入参数；结果进入专门对话页，避免首页同时承担输入与输出。

## 适配与交付
桌面为固定左导航和居中主区；手机导航收为顶部栏，参数换行，底部修改框固定，预览适配屏幕。所有图片为本地生成的灰阶 SVG 示意图，可单张下载。无外部资源、无 Dify 请求、无 API Key，可直接打开 index.html 使用。历史仅在当前浏览器保存；浏览器禁止本地存储时仍可在本次页面会话中使用。
