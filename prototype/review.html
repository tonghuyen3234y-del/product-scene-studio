DESIGN NOTES / 结构先行

一个创作入口，一条任务对话流。

用页面职责和状态转换承接复杂度，把输入框留给用户的创作需求。

01 / 页面职责

首页只负责发起创作。Slogan + IP 构成视觉锚点；自然语言是输入主体，参考图与三个参数组成次级操作区。

Chat 页承接提交、等待、结果与后续修改。每轮固定为“用户快照 → 助手任务块 → 结果块”。

预览层负责单图查看与下载，不改变创作上下文，也不另开一套编辑工作台。

02 / 首页组件

去掉「商品图」等重复说明文字，用上传入口、缩略图和移除操作表达素材状态。文字、图片与参数放在同一个提交容器中。

默认 3:4、两种都要、2 张；数量仅 1–4 张。上传参考图是必需项，文字可空，空时使用参数生成默认请求。

参数用可见当前值的紧凑选择控件，不做模式切换、模型切换或技能库。

03 / Chat 流架构

提交时冻结需求、素材和参数快照。首轮显示完整参考图，后续轮次沿用上下文；旧轮次保留，新轮次向下追加。

生成期间展示任务模块与结果骨架，底部输入区保留但不可提交。结果到达后原位替换骨架。

Planning 和需求澄清只划定容器位置。本阶段不确定话术、步骤数、自动触发规则或具体问答设计。

04 / 结果与反馈

生成完成出现 Toast，3 秒自动消失。图片墙是持久的完成反馈，Toast 不承担唯一状态通知。

点击图片进入模态预览，支持前后切换、下载、Esc 关闭；关闭后恢复原按钮焦点与对话位置。

预览无右侧工具栏，不放抠图、视频、局部重绘等未支持操作。下载的是示意 SVG，仅用于原型验收。

05 / IP 的交互边界

本版是黑白几何占位，悬停轻微抬起、点击点头。IP 靠近 Slogan，但不占用输入框，也不遮挡提交操作。

下一阶段可替换成静态待机图 + 按点击播放一次的短视频。优先用一次性动画，播放后回待机；减少动态效果的用户保持静态。

这次不制作视频素材，不确定品牌形象、品牌色或精细视觉。

06 / 失败与返回

素材读取失败就在输入框附近给出可操作错误，保留需求和已有有效素材；正常流程不堆叠常驻提示。

生成失败保留本轮及旧结果，点击原位重试。失败时不自动重发，以免重复消耗额度。

返回首页仍可恢复当前对话。新建创作重置会话，生成中禁用。刷新原型会清空演示数据。

07 / 适配与键盘

桌面居中单列 Chat 流；窄屏输入工具自然换行。结果保持两列缩略图，单图细节由预览层承接。

底部输入区固定，为内容流预留空间；生成完成保持结果可见。图标有无障碍名称，键盘可聚焦所有操作。

模态窗口约束焦点，支持左右键切图与 Esc 关闭；尊重减少动态效果设置。

08 / 真实能力与待确认项

现有服务已支持参考图、比例、场景、数量、首次生成和下载。此原型的自然语言、多轮修改及上下文沿用是待确认框架。

正式开发前要核验 Dify 是否消费 query、是否能沿用 conversation_id 并按修改需求重生成。若工作流不支持，先改工作流再开放入口。

本 HTML 不调用 Dify、不含密钥、不消耗额度。生成约 4 秒为演示；不是对正式生成耗时的承诺。

本轮需要确认的 4 个决定

  1. 首页采用 Slogan + 轻量 IP + 单一复合输入框。
  2. 点击生成进入独立 Chat 页，不在首页等待。
  3. 多轮结果按时间追加，底部沿用素材与参数继续修改。
  4. 单图预览使用模态层，只保留查看与下载。
